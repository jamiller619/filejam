HOW TO RUN A TASK MANUALLY
Open a fresh coding-agent chat in this existing checkout and send:

  Run node docs/browser-poc/packet.mjs 01.
  Execute only the task packet it prints. Read root AGENTS.md and the named
  source files. Preserve current user changes. Run the packet's checks and
  write its result receipt. Do not read all other tasks or execute the next one.

Replace 01 with the next number after the previous task passes.
The packet printer only reads files and prints text; it does not start agents,
call APIs, modify source, or run implementation commands.
Run one task at a time. Do not paste the whole planning folder into the chat.
Give the agent tools to read/edit local files and run commands; plain chat-only
text generation cannot execute the acceptance checks.

Useful commands:
  node docs/browser-poc/packet.mjs --list
  node docs/browser-poc/packet.mjs --check
  node docs/browser-poc/packet.mjs 05

KEEP COST CONTROLLED
Start with low reasoning and standard speed; don't default every packet to High.
Tasks05-06 provide an early calibration using supplied code and exact expectations.
Allow at most two focused repairs for the same failing check, then record the
failure and fix its owner task/packet. Do not silently upgrade every task's model,
spend indefinitely retrying, or claim success by changing expected results.
A fresh task reads its own packet and previous result, not the full conversation.
Full-repository checks occur at integration gates; small tasks use focused checks.
Repository formatting requirements still apply, preserving unrelated source.
